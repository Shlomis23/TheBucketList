# Rate limiting

מקום למימוש ה-rate limiting המבוזר מסעיף 11.2: 5 הנפקות הזמנה לשעה למשתמש,
20 ניסיונות בדיקה ב-15 דקות ל-IP. **אסור** להסתמך על זיכרון תהליך בודד
(Map בזיכרון לא שורד בין instances/deploys) — צריך מנגנון משותף
(טבלה ב-Postgres או שירות חיצוני) לפני production.

עדיין ריק בכוונה בשלב 0; נדרש לפני מימוש `createInvitation` בשלב 1.
